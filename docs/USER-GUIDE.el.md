# Οδηγίες χρήσης (προδιαγραφή — όχι ακόμη ενεργή λειτουργία)

## Για τον ανταποκριτή

Γράφεις κανονικά στο Etherpad. Όταν ολοκληρωθεί μια ανταπόκριση, προσθέτεις σε **ξεχωριστή γραμμή** το `POSTOK`. Δεν χρειάζεται να σταματήσεις να γράφεις την επόμενη ανταπόκριση.

Αν χρειάζονται εσωτερικές σημειώσεις που **δεν πρέπει να δημοσιευθούν**, περικλείονται ανάμεσα στις γραμμές `NOPUB` και `ENDNOPUB`.

Μπορείς να διορθώσεις παλιότερο δημοσιευμένο κείμενο μέσα στο pad: εφόσον η ταυτότητα του block παραμένει σαφής, η αλλαγή θα περάσει στο **ίδιο** Liveblog update μετά από περίπου 5″ χωρίς άλλες αλλαγές **στο συγκεκριμένο block**. Δεν χρειάζεται άλλη εντολή.

**Μην διαγράφεις ή μετακινείς POSTOK προηγούμενων αναρτήσεων** ως τρόπο διόρθωσης. Μπορεί να δημιουργηθεί αμφιβολία στην αντιστοίχιση και να χρειαστεί editor.

## Για τον editor (σχεδιαζόμενο)

Στην επεξεργασία Liveblog στο WordPress θα υπάρχει πλαίσιο «Σύνδεση Etherpad»: επικόλληση URL, έλεγχος σύνδεσης, ενεργοποίηση/παύση, κατάσταση και τυχόν σφάλματα.

Η πρώτη σύνδεση **δεν θα δημοσιεύει παλιά POSTOK** αυτόματα. Αν ένα υπάρχον Liveblog update έχει τροποποιηθεί χειροκίνητα στο WordPress, ο συγχρονισμός του συγκεκριμένου block θα σταματά μέχρι να επιλεγεί η σωστή εκδοχή.

## Κατάσταση υλοποίησης

Στην έκδοση 0.1.0 λειτουργεί μόνο η σελίδα διαγνωστικής κατάστασης στο **Εργαλεία → Etherpad to Liveblog**. Δεν υπάρχει ακόμη σύνδεση ή δημοσίευση.
