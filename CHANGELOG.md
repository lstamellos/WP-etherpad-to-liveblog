# Changelog

## 0.1.1 — 2026-10-23

- Added native WordPress third-party `Update URI` update checks against the latest published stable GitHub Release.
- Implemented validated ZIP release asset selection and plugin details modal, with cached API responses.
- Added GitHub Actions release packaging, PHP smoke tests and release instructions.
- WordPress administrators retain control of manual vs automatic updates.
- Etherpad/Liveblog sync and publishing remain disabled.

- Initialized WordPress plugin metadata and a read-only admin status page.
- Added architecture, control-string protocol, Greek development plan and test plan.
